# Protocol-Flexible Custom NFC Sensor Tag

Hardware design files and firmware for the sensor tag described in:

> R. Maeda and A. Noda, "Protocol-Flexible Custom NFC for Wire-Free Wearable Sensor Networks,"
> *IEEE Sensors Letters*, under review.

An NFC sensor tag whose communication protocol is defined in software rather than fixed in a
transponder IC. This repository holds the material that does not fit within the four-page limit of
the Letter. It is not a build guide; the schematic and the sources are the primary record, and
anything not stated here can be read from them.

This is a research prototype for protocol exploration. It is not optimized for power
(17 mW, battery-powered) and it does not implement, and is not interoperable with, ISO/IEC 14443.

## Reader hardware

Commercial boards, used as supplied, so no design files are included here:

- **X-NUCLEO-NFC08A1** (STMicroelectronics), carrying an **ST25R3916B** NFC reader IC and a
  47 mm x 34 mm four-turn 13.56 MHz printed antenna
- **NUCLEO-L476RG** (STMicroelectronics) as the host

The ST25R3916B was selected for its transparent mode, which bypasses the on-chip framing and coding
and gives the host microcontroller access to the baseband signals. Its automatic antenna tuning is
not used, and apart from the register writes in `reader.ino` the IC runs with its default settings.

## Build environment

Arduino IDE 2.3.10.

**Reader.** STM32duino core 2.12.0, board Nucleo-64 with part number Nucleo L476RG, upload by mass
storage. `U(S)ART support` must be set to *Enabled (no generic 'Serial')*, because the sketch
declares its own `HardwareSerial` instances.

**Tag.** The ATmega328P runs from its internal 8 MHz RC oscillator, so the stock Arduino board list
does not cover it. We used the *ATmega328 on a breadboard (8 MHz internal clock)* definition that
Arduino distributes as `breadboard-1-6-x.zip`
(<https://www.arduino.cc/en/uploads/Tutorial/breadboard-1-6-x.zip>, described at
<https://docs.arduino.cc/built-in-examples/arduino-isp/ArduinoToBreadboard/>). It is not
redistributed here, since its licence is not stated. The instructions on that page are for an older
IDE; with IDE 2.x we had to extract the archive into the Arduino data directory
(`%LOCALAPPDATA%\Arduino15\packages\` on Windows) rather than the sketchbook `hardware` folder.
Tested on Windows only.

`TAG_NUM` in `tag_sensor.ino` sets the address of each tag and must differ between them.

## Protocol

| | |
| --- | --- |
| Carrier | 13.56 MHz |
| Reader to tag | 10% ASK |
| Tag to reader | Load modulation, on-off keying on a 1 MHz subcarrier |
| Line code | Return-to-zero, generated by expanding UART output |
| UART baud rate | 100 kbaud (50 kbaud effective after RZ) |
| Request frame | 2 bytes |
| Reply frame | 3 acceleration bytes and 1 CRC byte |
| Slot time | 1.5 ms per tag |
| Polling rate | 222 Hz per tag with three tags |

`ERR_COUNT` in `reader.ino` selects the mode: when defined, the sketch counts failed polls per tag
instead of printing samples. It is set to 1000, the value used for the packet-error-rate
measurements in the paper.

## Meander coil

400 mm x 260 mm, copper tape on a fabric substrate, divided into six sections by series capacitors.
Measured with the loop opened: L = 1.7 uH, and with 82.5 pF in series the resonance is at 13.44 MHz
with |Z11| = 6.45 ohm, Q = 22.3 and a -3 dB bandwidth of 604 kHz. The coil follows prior work cited
in the paper and is not a contribution of this repository.
